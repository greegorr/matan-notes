\definitionticket{21}{Измеримая функция}
\label{definition:21}

\subsection*{Определение измеримой функции; критерий измеримости}

\subsubsection*{Определение}

\begin{definition}

Пусть \((X,\mathcal{C},\mu)\) --- пространство с мерой, \(f:E\to\overline{\mathbb{R}}\), \(E\in\mathcal{C}\). Функция \(f\) называется \textbf{измеримой на \(E\)}, если \[\forall a\in\mathbb{R}\qquad E(f<a)\in\mathcal{C}.\]

Варианты терминологии:

\begin{itemize}
\tightlist
\item
  если \(f\) задана на всём \(X\) и \(X(f<a)\in\mathcal{C}\) при всех \(a\) --- говорим просто «\(f\) измерима» (без указания множества);
\item
  в основной ситуации \(X=\mathbb{R}^m\), \(\mathcal{C}=\mathcal{M}^m\) (σ-алгебра лебеговских множеств), мера --- мера Лебега \(\lambda\): тогда измеримость называют \textbf{измеримостью по Лебегу}.
\end{itemize}

Это функции, «которым разрешено ставить вопрос об интегрировании»: ничего другого под значок интеграла не допускается.

\end{definition}

\subsubsection*{Критерий (лемма об эквивалентных определениях)}

В определении использован только один из четырёх типов множеств Лебега. Это законно:

\begin{lemma}

Для \(f:E\to\overline{\mathbb{R}}\), \(E\in\mathcal{C}\), эквивалентны утверждения:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \(\forall a\in\mathbb{R}\ \ E(f<a)\in\mathcal{C}\);
\item
  \(\forall a\in\mathbb{R}\ \ E(f\le a)\in\mathcal{C}\);
\item
  \(\forall a\in\mathbb{R}\ \ E(f>a)\in\mathcal{C}\);
\item
  \(\forall a\in\mathbb{R}\ \ E(f\ge a)\in\mathcal{C}\).
\end{enumerate}

\end{lemma}

\begin{proof}

\begin{itemize}
\tightlist
\item
  \textbf{(1) \(\Leftrightarrow\) (4)} и \textbf{(2) \(\Leftrightarrow\) (3)}: пары множеств взаимно дополнительны в \(E\) (замечание 9.1), а σ-алгебра замкнута относительно дополнений: из измеримости одного сразу измеримость другого (и обратно: \(E\) разбивается на две части --- если одна измерима, то и другая).
\item
  \textbf{(1) \(\Rightarrow\) (2)}: по замечанию 9.2 \(E(f\le a)\) --- счётное пересечение множеств вида \(E(f<a+1/n)\in\mathcal{C}\); σ-алгебра замкнута относительно счётных пересечений.
\item
  \textbf{(3) \(\Rightarrow\) (4)}: аналогично --- «неравенства однотипные, нестрогое через строгое»: \(E(f\ge a)=\bigcap_nE(f>a-1/n)\).
\end{itemize}

Цепочка замкнулась: (1)\(\Leftrightarrow\)(4)\(\Leftrightarrow\)(3)\(\Leftrightarrow\)(2).

\end{proof}

Итак, в определении можно использовать множества Лебега \textbf{любого} из четырёх типов --- те, про которые удобнее устанавливать измеримость.

\subsection*{Примеры измеримых функций}

\textbf{Пример 1 (характеристическая функция).} Если \(E\in\mathcal{C}\), то \(\chi_E\) измерима (на \(X\)). Множества Лебега: пока \(a\le 0\) --- \(X(\chi_E<a)=\varnothing\); как только \(a\) перескочит через 0 (т.е. \(0<a\le1\)) --- множество, где \(\chi_E=0\), т.е. \(X\setminus E\); как только \(a>1\) --- всё \(X\). Все три множества измеримы. (Обратно: если \(\chi_E\) измерима, то \(E=X\setminus X(\chi_E<1)\in\mathcal{C}\).)

\textbf{Следствие (ступенчатые с измеримыми ступеньками).} Если \(X=\bigsqcup_ie_i\), все \(e_i\in\mathcal{C}\), и \(f\) ступенчатая с этим допустимым разбиением, то \(f\) измерима: для любого \(a\) \[X(f<a)=\bigcup_{i:\,c_i<a}e_i\] --- конечное объединение измеримых множеств.

\textbf{Пример 2 (непрерывные функции).} Если \(f:\mathbb{R}^m\to\mathbb{R}\) непрерывна, то \(f\) измерима по Лебегу.

\begin{proof}

\(E(f<a)=f^{-1}\bigl((-\infty,a)\bigr)\) --- прообраз открытого луча. Для непрерывной функции прообраз открытого множества открыт (теорема 1 семестра о топологическом описании непрерывности). Открытые множества лежат в \(\mathcal{M}^m\). Значит, все множества Лебега первого типа измеримы.

\end{proof}

(Лектор: «загадка на общую хватку, не требует спецзнаний --- только философское понимание предмета». Используемое описание измеримых множеств: борелевское + мера ноль, открытые измеримы.)
