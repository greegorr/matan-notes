Ссылки начнут работать после первой успешной автоматической публикации.
PDF обновляется после принятия правок в `main` и завершения сборки.

Здесь ведём совместный студенческий конспект билетов.
Два начальных билета - примеры оформления; замените их материалом своего курса.

## Как помочь

- Знаете исправление? Откройте файл в `tickets/`, нажмите карандаш и предложите PR.
- Нашли проблему, но не знаете решения? Создайте Issue «Ошибка в билете».
- Один PR должен содержать одно связное исправление с кратким объяснением.

Модераторы проверяют математику, автоматическая сборка проверяет компиляцию.
Сейчас модератор проекта — [@greegorr](https://github.com/greegorr).

## Как устроен проект

| Путь | Назначение |
| --- | --- |
| `tickets/ticket-01.tex` | Исходник одного билета |
| `common/preamble.tex` | Общее оформление и команды |
| `main.tex` | Постоянный шаблон сборника |
| `scripts/build.py` | Поиск билетов и сборка PDF |
| `.github/workflows/build.yml` | Проверка PR и публикация в ветку `pdf` |
| `CONTRIBUTING.md` | Инструкция для участников |
| `SETUP.md` | Первичная настройка для владельца |

Новый файл `tickets/ticket-03.tex` автоматически попадёт в сборник.
Внутри укажите `\ticket{03}{Название билета}` и уникальную метку `\label{ticket:03}`.
Номер в команде и номер файла поддерживайте одинаковыми.
Скрипт сортирует файлы по числовому номеру и отклоняет дубликаты номеров.
Номер и название внутри билета проверяются при ревью.

## Сборка

```bash
python3 scripts/build.py
```

Результат: `build/tickets.pdf`. Зависимости описаны в CONTRIBUTING.md.
Результаты сборки в `main` не коммитим: публикацией занимается автоматика.

## Версия PDF

В ветке `pdf` рядом с документом лежит `SOURCE_COMMIT.txt`.
Он содержит коммит исходников, из которого собран документ.
В README этой ветки указаны ссылка на исходники и время сборки в UTC.
